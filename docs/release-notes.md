## Что нового в 4.5

- **Проверка обновлений.** Раз в сутки монитор спрашивает у GitHub, не вышла ли новая версия. Если вышла, это видно в боковой панели и в «Настройки → Сервер», а в журнал и Telegram приходит одно сообщение. Сам монитор ничего не скачивает и не устанавливает. Проверку можно выключить в настройках.
- **Готовые сборки.** EXE теперь собираются автоматически и прикладываются к каждому релизу — Python для установки не нужен.

Версия включает всё из 4.4: копии конфигурации роутера с историей изменений, справочник сотрудников со сроками доступа, заполнение пула адресов и лицензий AnyConnect, скрытие в аудите учёток, удалённых на роутере.

## Что скачать

| Файл | Для чего |
|---|---|
| `CiscoAnyConnectServer-…-server-package.zip` | Установка и обновление на Windows Server: распаковать и запустить `Install-Server.bat` от имени администратора. База и настройки при обновлении сохраняются. |
| `CiscoAnyConnectServer.exe` | Сервер с веб-панелью для запуска на обычном компьютере. |
| `CiscoAnyConnectMonitor.exe` | Старое настольное приложение (не развивается). |
| `SHA256SUMS.txt` | Контрольные суммы файлов. |

Файлы не подписаны, поэтому Windows SmartScreen может показать предупреждение при первом запуске.
