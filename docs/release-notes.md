## Что нового в 4.6

Геолокация стала точнее, а там, где точной быть не может, это видно:

- **Локальная база DB-IP.** Монитор сам скачивает её раз в месяц и определяет адреса у себя: без лимитов, без задержки и даже когда ipinfo.io недоступен.
- **Два источника.** Город сверяется по DB-IP и ipinfo.io. Если они называют разные города, рядом стоит «?», а в подсказке видно, кто что ответил.
- **Мобильные операторы.** Адреса Kcell, Beeline, Tele2/Altel, Jusan Mobile и других помечены «моб.»: город у них — место выхода оператора в интернет, а не человека.
- **Свои подписи сетей.** «Офис Астана», «Дом Иванова» для адреса или сети — важнее любой базы. И проверка любого адреса по всем источникам.
- **Ответы ipinfo.io обновляются** каждые 3 дня, а не хранятся вечно.

Версия включает всё из 4.5: проверку обновлений и готовые сборки к каждому релизу.

| Файл | Для чего |
|---|---|
| `CiscoAnyConnectServer-…-server-package.zip` | Установка и обновление на Windows Server: распаковать и запустить `Install-Server.bat` от имени администратора. База и настройки при обновлении сохраняются. |
| `CiscoAnyConnectServer.exe` | Сервер с веб-панелью для запуска на обычном компьютере. |
| `CiscoAnyConnectMonitor.exe` | Старое настольное приложение (не развивается). |
| `SHA256SUMS.txt` | Контрольные суммы файлов. |

Файлы не подписаны, поэтому Windows SmartScreen может показать предупреждение при первом запуске.
